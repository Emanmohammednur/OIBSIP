# Degree - Temperature Converter

I built **Degree** as a simple way to convert a temperature without having to work through the formulas yourself. Enter a value, choose whether it is in Celsius, Fahrenheit, or Kelvin, and the converter shows the equivalent in all three scales.

The interface is designed to feel calm and easy to use, with a forest backdrop and clear feedback when an entry needs attention.


## What it does

- Converts temperatures between Celsius, Fahrenheit, and Kelvin
- Checks that entries are numeric and above absolute zero
- Explains invalid entries with clear messages
- Displays each result to two decimal places
- Adapts to different screen sizes

## Try it

No installation or build step is needed. Open `index.html` in a modern web browser and start converting.

## Built with

- HTML for the page structure
- CSS for the responsive layout and visual design
- JavaScript for conversion and input validation
