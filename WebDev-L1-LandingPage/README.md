# TechNova Digital Landing Page

A responsive static landing page for **TechNova Digital**, a fictional digital solutions agency. This project was created for Oasis Infobyte Web Development Internship Program (OIBSIP), Level 1 · Task 1.

## Overview

The page introduces the brand and presents its services, selected projects, client testimonials, and contact information. Visitors can use the sticky navigation and calls to action to move between sections.

## Features

- Sticky navigation with links to the main page sections
- Hero section with headline, supporting text, and calls to action
- Separate services, about, projects, testimonials, and contact sections
- Footer with social links and newsletter area
- Consistent dark visual theme and responsive layouts
- No JavaScript or build tools required

- HTML5
- CSS3 (Flexbox, Grid, and media queries)

## Run Locally

No installation is required. Open `index.html` in a web browser. For local live reload, open the repository in VS Code and use the Live Server extension.

## Responsive Checks

The page was checked at viewport widths of **1440 px**, **820 px**, **390 px**, and **320 px**. At those sizes, the navigation remained sticky, the page had no horizontal overflow, and the main card groups did not overlap.
