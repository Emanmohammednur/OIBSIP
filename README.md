# OIBSIP Web Development Portfolio

**A collection of front-end projects built during the Oasis Infobyte Web Development Internship Program.**

This repository brings together projects from two internship levels, from responsive page design to interactive browser-based tools. Each project is self-contained and includes its own source files and documentation.

## Project Directory

| Level | Project | Overview | Technologies |
| --- | --- | --- | --- |
| **1** | [Personal Portfolio](./Level%201/Personal_Portfolio/index.html) | A personal site showcasing my background, skills, certificates, and selected work. | HTML · CSS · JavaScript |
| **1** | [Temperature Converter](./Level%201/Temperature_Convertor/index.html) | Converts temperatures between Celsius, Fahrenheit, and Kelvin, with input validation. | HTML · CSS · JavaScript |
| **1** | [TechNova Digital Landing Page](./Level%201/WebDev-L1-LandingPage/index.html) | A responsive landing page for a fictional digital agency. | HTML · CSS |
| **2** | [Calculator App](./Level%202/Calculator%20App/index.html) | A browser calculator for arithmetic expressions, with chained calculations and keyboard input. | HTML · CSS · JavaScript |

## Explore by Level

- [Level 1 projects](./Level%201/README.md) — portfolio, temperature converter, and landing page.
- [Level 2 projects](./Level%202/README.md) — calculator app.

## Run a Project

No package installation or build step is required. Open a project's `index.html` file in a modern browser. For local live reload, open the repository in VS Code and use the Live Server extension.
